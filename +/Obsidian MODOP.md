# Shortcut

ctrl n : nouvelle note
ctrl ; : add properties (to add : created date/tag)
ctrl shift f : search
ctrl m : move a note to atlas 

To created a new note and you want to add it in Atlas/Map, in your note : 
crochet crochet : add a link to a note [[Obsidian MODOP]]

To add link to a doc : 
copy your doc : C:\Aydan\AydanVerse\Atlas\Utilities\Doc
create a new note, ex : Coach pro
[[name of the document]]

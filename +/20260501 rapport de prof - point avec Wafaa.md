**Slide 55 : Deont

![[Pasted image 20260501191547.png]]

Dans le cadre de mon activite de coach pro, je m'engage a exercer ma pratique dans le respect des principes ethiques et deontologique du metier. notamment le code de deontologie de ICF, que je m'engage a respecter dans ma pratique.
Cet engagement se tradut concretement dans mon cadre d'intervention, formalise à traver mon contrat de caoching. 
avec aussi ma posture : une posture neutre, bienveillante, non directive, sans jugement, sans opinion 
attention sur le protection des données personnelles : Règlement Général sur la Protection des Données (RGPD)
Conformément au Règlement Général sur la Protection des Données (RGPD), le Coach informe le Client que les données personnelles recueillies (coordonnées, notes de séances, informations partagées) sont conservées dans un fichier sécurisé et protégé par mot de passe.
